## 🚀 Projects

### 🤖 [LLM Agent — GAIA Style](https://huggingface.co/spaces/kingwar1/AGENT-GAIA)
> Built an LLM-based agent for multi-step reasoning tasks inspired by GAIA-style problems. Combines structured execution with reasoning to handle complex queries reliably.

**Key learnings:** LLMs need control · System design > model choice · Reliability > raw capability

---

### 🏥 [Medical Chatbot — RAG](https://github.com/Amit95688/MEDICAL-CHATBOT)
> Retrieval-augmented chatbot using embeddings and vector search to answer medical queries from a curated knowledge base — minimizing hallucination over pure generation.

**Key learnings:** Retrieval quality defines everything · Chunking strategy matters · LLM eval is hard

---

### 🥗 [Nutrition Dataset](https://huggingface.co/datasets/kingwar1/nutri_food)
> Structured dataset for nutrition-based AI queries, usable for training or evaluation in food/health AI systems.

**Key learnings:** Data quality > model quality · Building datasets is harder than using them

---

### 🧠 [RSNA Intracranial Aneurysm Detection](https://www.kaggle.com/competitions/rsna-intracranial-aneurysm-detection)
> Deep learning pipeline for aneurysm detection on real-world noisy medical imaging data from the RSNA Kaggle competition.

**Key learnings:** Real data is messy · Debugging is a core skill · Pipelines break more than models
