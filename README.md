[Live Demo](https://huggingface.co/spaces/kingwar1/AGENT-GAIA)

Built an LLM-based agent for multi-step reasoning tasks inspired by GAIA-style problems. The system handles complex queries by combining reasoning with structured execution.

**What I learned:**
- LLMs hallucinate easily and need control
- Prompting alone is not enough
- Reliability matters more than raw capability
- System design matters more than model choice

### 2. Medical Chatbot — RAG
[GitHub](https://github.com/Amit95688/MEDICAL-CHATBOT)

Built a retrieval-augmented chatbot using embeddings and vector search to answer medical queries based on a knowledge base instead of pure generation.

**What I learned:**
- RAG reduces hallucination but depends heavily on retrieval quality
- Chunking and context selection matter a lot
- Evaluation is not straightforward in LLM systems
